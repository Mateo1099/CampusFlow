# Skills de Kiro para CampusFlow

Pega aquí (dentro de `.kiro/skills/`) cada carpeta de skill como una subcarpeta independiente, por ejemplo:

```
.kiro/skills/
├── campusflow-ai-operator/
├── campusflow-architect/
├── campusflow-change-authorizer/
├── campusflow-feature-planner/
├── campusflow-implementation-coach/
├── campusflow-quality-guardian/
└── campusflow-ui-regression-checker/
```

Cada carpeta de skill debe contener al menos un archivo `SKILL.md` en su raíz (es el formato que Kiro reconoce automáticamente).

Puedes borrar este archivo README.md una vez que hayas pegado tus skills reales.
